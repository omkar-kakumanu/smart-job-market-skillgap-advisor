## Managing Job Descriptions
1. Log in as an Administrator.
2. Click **Admin Portal** in the sidebar.
3. Fill out the **Post New Industry Job** form with position title, company, location, experience tier, and salary range.
4. Click **Publish Job Posting**.
5. Existing jobs can be deleted using the trash icon next to each active job listing.
